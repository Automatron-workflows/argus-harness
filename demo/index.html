Switch the snapshot. The contracts do not change; the labels, gaps and audit findings do.

The primitives that are locked.

A metric is not a column name. It carries a unit, direction, aggregation, null policy, owner and version.

Why the unit and null policy matter.

A percent is stored as a fraction, not 34.38. A cumulative counter may only step down after an explicit reset. A missing date is a gap; the renderer leaves it blank. These rules are checked before a dashboard reaches a reader.

The same contract, whatever the source.

        
Static JSON for a preserved snapshot, HTTP for a product API, CSV for an export, BigQuery for the warehouse.

      

    

    

    

      Looker Studio is a peer, not an enemy.
      
Generate the same catalog as BigQuery tables and views. Looker Studio can read those views for exploration while the harness renders the code-owned dashboard. Both use the same metric keys, units and null policy.

    

  


  

    

      

        
Share the semantic layer with Looker Studio.

        
The harness writes BigQuery DDL, views and a field map. It does not call the Looker Studio API or manage credentials.

      

      

        
        
      

    

    

      

        
BigQuery view

        
v_metric_daily joins measured rows to the catalog. v_metric_latest applies one latest-row rule. v_metric_health exposes freshness and source status.

        

      

      

        
Looker Studio field map

        
Labels, units, directions and descriptions come from the same catalog. The field map is a mapping, not a connector.

        

          
Looker Studio field map

        

      

    

    

      What is not guaranteed.
      
Looker Studio blends, calculated fields and report-level aggregation can change a metric's meaning. Review them against the catalog. A rendered report is not evidence that its source rows are fresh or complete.

    

  


  

    

      

        
Audit the dashboard, not the screenshot.

        
Checks cover source agreement, freshness, missing metrics, gaps, cumulative resets, units, chart thickness and definitions.

      

      
    

    

    

  


  

    
Run it

    
Start with one measured dashboard.

    
Clone the harness, create a warehouse project, replace the fictional snapshot, then run the audit before you publish.

    
git clone https://github.com/Automatron-workflows/argus-harness.git
node argus-harness/bin/argus-harness.mjs init ./my-warehouse --template warehouse
cd my-warehouse
node ../argus-harness/bin/argus-harness.mjs doctor --project .
node ../argus-harness/bin/argus-harness.mjs audit --project . --source custom-local
node ../argus-harness/bin/argus-harness.mjs render --project . --source bigquery --out dashboard.html
node ../argus-harness/bin/argus-harness.mjs audit --project . --source bigquery --out evidence.json

    
Node 20 or newer. No npm dependencies, model calls or telemetry. The starter data is fictional. MIT licensed.
