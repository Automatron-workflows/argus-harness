# Support

Open an issue with:

- the command you ran;
- the relevant project files (with secrets removed);
- the exact error or audit finding;
- the Node version and operating system.

Useful issues are reproducible: a small snapshot, a metric contract and the
expected/actual dashboard state. For a source adapter, include the row shape and
the failure mode, never a live token.

This is a small open-source harness with no service-level agreement. It is not a
hosted analytics service.
